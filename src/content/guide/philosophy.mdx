## 安全

### Agent 不新增入站端口

- **不监听任何端口。** 连接由 agent 主动向 hub 发起，目标机器不必开端口，也不必改防火墙
- **监控采集不写文件。** 指标采集只读 `/proc`、`/etc/os-release` 和 `statvfs`，没有数据库或缓存。
  累加流量、识别重启这些有状态的事都在 hub 侧
- **终端不需要 SSH 凭据。** 管理员主动打开 Web Terminal 时，Cagent 以 root 权限创建本地 PTY；
  hub 只转发输入输出，不保存密码或私钥
- **不自动更新。** 自更新等于让 agent 有权以 root 下载并执行任意二进制。升级是重跑一遍安装命令

### 权限边界

Cagent 是节点的远程管理通道，因此服务以 root 运行，Web Terminal 拥有与 root SSH 会话相同的主机
权限。Cagent `v1.1.1` 起会检查运行身份，非 root 服务只能继续上报监控数据，不能创建终端。

| | agent | hub |
|---|---|---|
| 身份 | root | 专用系统用户 `monitor` |
| 主机权限 | 完整系统访问，供 root PTY 使用 | `ProtectSystem=strict` + `ProtectHome`，只允许写 `data/` |
| 网络 | 主动连接 hub，不监听端口 | 只监听回环地址，由反向代理提供 HTTPS 入口 |
| 凭证 | 节点 token 存在 root-only 环境文件中，不传给 shell | 登录会话只在数据库中保存 sha256 |

hub 仍然降权并使用 systemd 沙箱，因此连自己的二进制都改不了：可写的只有数据库和主题所在的目录。
Agent 不使用会阻止 root 终端访问宿主文件系统的沙箱。

节点 token 写在 `/opt/monitor/agent.env`，权限 `0600`，不写进服务定义——那些内容会出现在
`systemctl cat` 和日志里。Cagent 读取连接参数后会从自身环境中移除 `MONITOR_TOKEN` 与
`MONITOR_SERVER`，创建 shell 时再明确移除一次。

<Note warn>
  Web Terminal 是完整的 root 远程命令入口。只有可信管理员才能获得后台登录权限；应使用 HTTPS，
  并及时撤销不再需要的 GitHub 白名单账号和管理会话。
</Note>

### 凭证的边界

- 节点 token 是 256 位随机值，走 `Authorization: Bearer` 头而不是 URL query——query 会进反代的
  access log。它只能上报自己那一个节点，读不到别的节点，也改不了任何设置
- 换发 token 立刻生效，包括已经连着的那条连接
- 会话是 256 位随机 token，数据库里只存 sha256，14 天过期。cookie 带 `HttpOnly` 与
  `SameSite=Lax`，HTTPS 下加 `Secure`
- 面板的每个 handler 在参数里带一个 `Admin` 提取器，框架在进入函数体之前校验会话，所以不会写漏
- 应急密码用 argon2id 存。登录限流是同一地址 15 分钟 5 次失败锁死，另有一道并发闸门，
  同一时刻只允许一次密码校验

### 装完，面板不在公网上

一键脚本写死 `--listen 127.0.0.1`。装完那一刻面板打不开，要先配一段反向代理。

这是最容易被当成 bug 的一条，而代价很实在：明文 HTTP 上，会话 cookie 和节点 token 在链路上都是明文，
中间人还能替换掉安装命令下载的那个二进制，而它接着会以 root 跑起来。所以 agent 和 `install.sh`
一律拒绝明文连远程 hub。

[反向代理](/install/reverse-proxy)那一页有三种配法，抄就行。

## 极简

### 零配置文件

hub 只有四个命令行参数：`--listen`、`--db`、`--themes`、`--site`。其余全部存在 SQLite 里，在面板改。

少一个 TOML 解析器，也少了「配置文件在哪、权限对不对、和数据库同不同步」这一类问题。

### 不做的功能

| 不做 | 原因 |
|---|---|
| 负载告警 | 阈值、持续时长、节点范围是一整套规则引擎。通知只做掉线、流量、到期、登录这几件判定明确的事 |
| SSH 密码 / 私钥托管 | 凭据不进入 hub。Web Terminal 复用 Cagent 已建立的连接，在节点本地创建 root PTY |
| 插件系统 | 等于把第三方代码请进 hub 的进程 |
| ICMP / HTTP 探测 | TCP 一种够用，三种要三套超时语义、三套图例 |
| agent 自动更新 | 自更新意味着 agent 能以 root 下载并执行任意二进制 |
| 跨平台 agent | 加 Windows / macOS 等于推翻整个采集实现 |

这些不是排期靠后，是不会做。Web Terminal 是唯一的远程命令入口，并被限制在已登录管理员、在线
Cagent 和节点本地 root PTY 这三层边界内。

## 高效

同一台机器、同一套负载的实测数字，完整数据在[性能](/reference/performance)：

| | |
|---|---|
| 可执行文件 | 6.0 MiB |
| 冷启动到能响应请求 | 63 ms |
| 空转内存 | 6.1 MiB |
| 200 个节点在线，每 2 秒上报 | 8.4 MiB，一颗核的 2.5% |
| 每秒 1000 次上报 | 8.6 MiB |

Rust 没有 GC 也没有语言运行时，负载上去内存基本不动。但光换语言只拿得到体积和内存的优势，
响应速度是一处一处调出来的，那几处改动记在同一页里。
