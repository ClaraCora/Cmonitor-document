Web Terminal 通过节点上已经在线的 Cagent 打开本地 PTY。它不使用 SSH 协议，不需要 SSH 密码、
私钥或 `sshd`，也不要求节点开放 22 端口。

```text
浏览器 ──WebSocket──▶ Cmonitor hub ──已有 Agent WebSocket──▶ Cagent ──▶ 本地 PTY
```

hub 负责管理员会话校验和消息转发。真正的 shell 进程在目标节点上由 Cagent 创建。

## 安全更新建议

| 组件 | 推荐版本 |
|---|---|
| Cmonitor hub | `v1.2.6` |
| Cagent | `v1.1.3` |

这些版本包含终端连接撤销和 TLS 握手安全修复。后台顶部可以查看运行中的 Hub 版本，节点列表显示
Cagent 版本。先更新 Hub，再重跑节点安装命令，即可更新固定版本的 Cagent 和服务定义。

## 打开终端

1. 登录 Cmonitor 管理后台
2. 打开**节点**列表，确认目标节点在线
3. 点击节点操作列中的终端图标
4. 看到“已连接”后直接输入命令

关闭对话框、浏览器断开、agent 掉线或 shell 退出时，Hub 会清理对应的 PTY 和交互进程。
退出登录、撤销会话、重置节点 Token、删除节点或替换 Agent 连接，也会关闭关联终端。

每个节点最多同时打开 4 个终端，Hub 总计最多 32 个。终端连接建立与数据发送有超时限制，避免卡住的
连接持续占用资源。浏览器终端和实时数据连接要求与 Hub 同源。

远程连接必须使用 WSS 加密；即使 Agent 使用 `--insecure` 继续上报监控数据，远程明文连接也不能打开
root 终端。仅本机回环连接可用于调试。

## 终端权限

默认安装会让 Cagent 服务以 root 运行，Cagent 创建的 PTY 因此拥有目标节点完整的 root 权限。
Cagent `v1.1.1` 起会检查运行身份；如果服务不是 root，监控数据仍可继续上报，但终端请求会被拒绝。

Cagent 在启动 shell 前移除 `MONITOR_TOKEN` 与 `MONITOR_SERVER`，所以在终端里执行 `env` 不会看到
节点 token 或 hub 地址。hub 也不保存任何 SSH 凭据。

<Note warn>
  Web Terminal 仍然是远程命令执行入口。只给可信管理员登录权限，使用 HTTPS，并及时撤销不再需要的
  GitHub 白名单账号或管理会话。
</Note>

## 常见问题

### 终端按钮是灰色

节点当前离线。先检查 `monitor-agent` 服务和 `/api/agent/ws` 的反向代理配置。

### 打开后提示无法启动终端

确认节点已升级到 Cagent `v1.1.1` 或更高版本，并且系统存在 `/bin/bash` 或 `/bin/sh`。

### 提示 Cagent 未以 root 运行

重新执行面板生成的节点安装命令。Cmonitor `v1.2.5` 起的安装脚本会同时更新 Cagent 二进制和服务定义，
让 systemd 或 OpenRC 以 root 启动 Cagent。
